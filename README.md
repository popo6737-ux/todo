# 속초 세일즈 워크샵 비교

8명, 총예산 160만 원을 기본값으로 하는 비공개 1박 2일 비교 사이트입니다. 세 후보 모두 첫날 울산바위를 왕복 등반합니다. 세일즈 자료 미팅은 둘째 날 오전 선택 일정이며, 이후 근처에서 점심을 먹고 산책한 뒤 복귀합니다. 인원·예산·견적 항목을 바꾸면 총액, 1인당 금액, 조건별 추천이 자동 갱신됩니다. 예산 및 금액 입력에는 천 단위 쉼표가 표시됩니다. 변경 사항은 현재 브라우저의 로컬 저장소에만 남습니다.

## 독채 숙소 후보

| 후보 | 숙소 안내 | 침실·욕실 | 침실 내 욕실 확인 |
| --- | --- | --- | --- |
| 속초 근처 | [고성 살구네집](https://www.airbnb.co.kr/rooms/1651173590598943860) | 침실 4, 욕실 4, 최대 10명 | 위치 미확인 |
| 아야진 | [뽕스테이](https://www.airbnb.co.kr/rooms/672941760611272961) | 침실 4, 욕실 2, 최대 8명 | 위치 미확인 |
| 양양 | [요트랑 클럽하우스](https://www.airbnb.co.kr/rooms/716231742019185743) | 침실 4, 침실별 개별 욕실 안내, 8인 기준 | 4개 안내 |

기본 설정인 `침실 내 욕실 2개 이상 확인`을 켜면 욕실 배치가 확인된 양양 후보만 추천 대상입니다. 다른 두 숙소의 욕실이 침실 안에 있는지 추가 확인이 필요합니다. 양양 후보는 속초 숙소보다 복귀 동선이 달라집니다.

## 가견적과 확인 사항

- 방문 날짜를 받지 않아 독채 숙박비 42만~52만 원을 포함한 **모든 금액은 기획 가정액**입니다. 실제 요금, 8인 추가 비용, 예약 가능 여부를 확인하고 사이트에서 수정해야 합니다.
- 뽕스테이는 숙소 안내에 6인 기본요금이 표시되어 있습니다. 8인 이용 시 추가요금을 확인해야 합니다.
- 이동비는 팀 차량 2대의 유류비와 통행료를 가정합니다. 차량 대여 비용이나 출발지별 차이는 반영하지 않았습니다.
- 06:00 수도권 출발, 09:00 소공원 도착을 임시로 잡았습니다. 실제 출발지와 교통 상황에 따라 앞당겨야 할 수 있습니다.
- 울산바위 코스는 소공원 출발 편도 3.8km·안내 약 2시간입니다. 8명 단체와 식사·휴식을 감안해 산행 블록을 09:30–14:30으로 잡았습니다. 당일 입산시간과 탐방로 통제 정보를 국립공원공단에서 확인해야 합니다. 통제나 악천후 시 등반을 강행하지 않고 일정을 조정합니다.
- [속초관광](https://www.sokcho.go.kr/ct/tour) 정보도 참고할 수 있습니다. 외부 예약은 하지 않았습니다.

## 로컬 실행

`npm run build` 후 `python3 -m http.server 4173 --directory dist`.

`npm test`는 합계·1인당 금액, 금액 변경, 침실 내 욕실 확인에 따른 추천과 공통 일정을 검증합니다.
