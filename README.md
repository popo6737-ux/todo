# 속초 세일즈 워크샵 비교

**사이트 주소:** [속초 세일즈 워크샵 비교 열기](https://sokcho-team-workshop.popo6737.chatgpt.site)

사이트는 로그인 없이 열 수 있습니다. 링크를 아는 누구나 볼 수 있으므로 내부 기밀이나 개인 정보를 입력하지 마세요. 이 GitHub 저장소도 공개되어 있으며, 사이트는 GitHub Pages가 아닌 Sites에서 호스팅합니다.

2026년 10월 15~16일, 8명, 총예산 160만 원의 1박 2일 워크샵 일정과 예산을 조정하는 사이트입니다. **양양 요트랑펜션 숙소는 예약 완료**되었고, 첫날 울산바위 등반 후 장을 봐서 야외 BBQ를 합니다. 둘째 날에는 11시 전에 퇴실하고 낙원식당에서 점심을 먹은 뒤 주변을 산책하고 복귀합니다. 세일즈 자료 미팅은 필요할 때 둘째 날 오전에 둡니다. 다른 두 숙소 카드는 이전 비교용 후보입니다.

## 확정 숙소와 주의사항

- 예약일: 2026년 10월 15일 입실(15:00), 16일 퇴실(11:00 전). 예약자 성함은 공개 사이트와 저장소에 기재하지 않았습니다.
- 객실 내 구이와 흡연, 반려동물, 개인 버너 사용 제한. **우천 시 야외 BBQ 불가**이므로 날씨에 따른 저녁 대안을 따로 정해야 합니다.
- 주차는 펜션 옆 또는 약 10m 거리 공영주차장 안내. 요트 체험 1인 25,000원은 선택 가능 옵션이며 예약된 일정과 기본 합계에 포함하지 않았습니다. 추가 침구 세트는 20,000원입니다.
- 기존에 조사한 요트랑 클럽하우스의 침실별 욕실 정보는 예약 객실과 대조 확인이 필요합니다.

## 칠판 계획액

| 항목 | 8인 계획액 |
| --- | ---: |
| 숙박 | 600,000원 |
| 1일차 도시락 (20,000원 × 8) | 160,000원 |
| BBQ 고기 2kg | 96,000원 |
| 회 | 150,000원 |
| 식음료·잡비 | 100,000원 |
| 2일차 낙원식당 점심 (25,000원 × 8) | 200,000원 |
| **입력된 비용 합계 / 1인당** | **1,306,000원 / 163,250원** |

160만 원 예산에서 입력된 비용 기준 잔액은 294,000원입니다. **이동비와 조식은 금액 미입력으로 합계에서 제외**되며, 사이트에서 입력하면 합계와 1인당 비용이 자동 갱신됩니다. 숙박·식사 금액은 칠판의 계획액이며 실제 결제금액 확인값은 아닙니다. 각자의 변경 사항은 현재 브라우저에만 저장되고 팀원 간 자동 공유되지 않습니다. 예약 변경이나 외부 결제는 사이트에서 하지 않습니다.

울산바위 등반의 입산 시간과 탐방로 통제는 [국립공원공단](https://www.knps.or.kr/front/portal/visit/visitCourseSubMain.do?menuNo=7020093&parkId=120400)에서 당일 확인하세요. 산행이 통제되면 등반을 강행하지 않고 일정을 조정해야 합니다.

## 로컬 실행

`npm run build` 후 `python3 -m http.server 4173 --directory dist`.

`npm test`는 합계·1인당 금액, 금액 변경, 침실 내 욕실 확인에 따른 추천과 공통 일정을 검증합니다.
